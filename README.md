# Person Monitor Bot — reconstructed latest

Локальний Telegram-бот для **ручного моніторингу публічних згадок** про осіб. Цей ZIP реконструйовано 07.08.2026 зі старішої резервної копії та змін, які були виконані й перевірені у чаті.

> Важливо: секрети `.env` та найсвіжіший локальний `data/data.json` з Mac у пакет не входять. Деталі — `RECOVERY_NOTES.md`.

## Що вміє поточна версія

- постійне Telegram-меню;
- додавання, перегляд, редагування та видалення суб’єктів;
- перевірка вибраної особи кнопкою без UUID;
- повний згрупований звіт у Telegram;
- Excel + PDF після кожної перевірки;
- повторне формування Excel/PDF зі збережених даних без нового пошуку;
- судовий open-data index;
- дедуплікація згадок.

## Джерела

- Google News RSS;
- Google web через SerpApi / Serper.dev;
- відкритий API декларацій НАЗК;
- Реєстр корупціонерів НАЗК;
- офіційні сайти;
- Prozorro;
- Судова влада України — open data «Стан розгляду справ»;
- судовий вебпошук як fallback.

YouTube/Telegram/Facebook ще не підключені.

## Запуск на новому ПК

### 1. Встановіть Node.js 22+

```bash
node -v
```

### 2. Встановіть залежності

У папці проєкту:

```bash
npm install
```

### 3. Створіть `.env`

Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

macOS/Linux:

```bash
cp .env.example .env
```

Заповніть принаймні:

```env
TELEGRAM_BOT_TOKEN=
ALLOWED_TELEGRAM_CHAT_IDS=
SERPAPI_API_KEY=
SERPER_API_KEY=
```

Для звичайного Google достатньо одного з двох пошукових ключів.

### 4. Запустіть

```bash
npm start
```

У Telegram виконайте `/start`.

## Відновлення старих даних з Mac

Коли з’явиться доступ до Mac, скопіюйте до цієї папки:

```text
.env
data/data.json
data/court-open-data/index.json
```

Це поверне токени, список суб’єктів, історію згадок і вже побудований судовий index.

## Судовий open-data index

Після додавання суб’єктів можна перебудувати локальний індекс:

```bash
python3 scripts/update-court-open-data-index.py
```

Архів дуже великий, тому потрібні вільне місце на диску, `curl`, Python 3 і стабільний інтернет.

## Обмеження

- жодного обходу CAPTCHA;
- закриті соцмережі та платні реєстри не перевіряються;
- Google-пошук залежить від зовнішніх API-ключів і їхніх лімітів;
- збіг — це технічна оцінка, а не юридичне підтвердження особи;
- бот працює лише поки локальний процес запущений.
